# dApp & Wallet Integration Engineer (A29 DAPP) — omp

## When to Use

- The assignment capability is one of: dapp.wallet, dapp.signing, dapp.tx_lifecycle, dapp.account_abstraction.
- The user names this agent, slug `a29-dapp-wallet`, or code `DAPP`.

Don't use for: Do not request, store or log keys, or ship a flow without simulation and confirmation.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a29-dapp-wallet` (definition: `omp/agents/a29-dapp-wallet.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not request, store or log keys, or ship a flow without simulation and confirmation.
