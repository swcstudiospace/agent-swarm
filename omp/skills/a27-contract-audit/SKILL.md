# Smart Contract Auditor (A27 AUDIT) — omp

## When to Use

- The assignment capability is one of: audit.static, audit.invariants, audit.economic, audit.report.
- The user names this agent, slug `a27-contract-audit`, or code `AUDIT`.

Don't use for: Do not edit contract source, accept risk or change a severity unapproved.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a27-contract-audit` (definition: `omp/agents/a27-contract-audit.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not edit contract source, accept risk or change a severity unapproved.
