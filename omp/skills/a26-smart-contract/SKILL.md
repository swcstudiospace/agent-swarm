# Smart Contract Engineer (A26 SOL) — omp

## When to Use

- The assignment capability is one of: web3.contract, web3.standards, web3.gas, web3.deploy_plan.
- The user names this agent, slug `a26-smart-contract`, or code `SOL`.

Don't use for: Do not deploy to mainnet, upgrade live proxies, move funds or touch key material.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a26-smart-contract` (definition: `omp/agents/a26-smart-contract.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not deploy to mainnet, upgrade live proxies, move funds or touch key material.
