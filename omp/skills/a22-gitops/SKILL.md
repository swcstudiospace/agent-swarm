# GitOps & Progressive Delivery Engineer (A22 GITOPS) — omp

## When to Use

- The assignment capability is one of: gitops.reconcile, gitops.manifest, gitops.rollout, gitops.promotion.
- The user names this agent, slug `a22-gitops`, or code `GITOPS`.

Don't use for: Do not merge PRs or prune production without approval.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a22-gitops` (definition: `omp/agents/a22-gitops.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not merge PRs or prune production without approval.
