# Kubernetes Cluster Operator (A21 K8S) — omp

## When to Use

- The assignment capability is one of: cluster.lifecycle, cluster.capacity, cluster.upgrade, cluster.fleet.
- The user names this agent, slug `a21-cluster-ops`, or code `K8S`.

Don't use for: Do not mutate production clusters or delete a cluster without approval.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a21-cluster-ops` (definition: `omp/agents/a21-cluster-ops.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not mutate production clusters or delete a cluster without approval.
