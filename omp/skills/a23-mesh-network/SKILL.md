# Service Mesh & Networking Engineer (A23 MESH) — omp

## When to Use

- The assignment capability is one of: mesh.traffic, mesh.policy, mesh.ingress, mesh.netpol.
- The user names this agent, slug `a23-mesh-network`, or code `MESH`.

Don't use for: Do not flip strict mTLS or change production mesh without approval.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a23-mesh-network` (definition: `omp/agents/a23-mesh-network.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not flip strict mTLS or change production mesh without approval.
