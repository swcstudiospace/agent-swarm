# FinOps & GreenOps Analyst (A20 FINOPS) — omp

## When to Use

- The assignment capability is one of: finops.model, finops.rightsize, finops.budget, finops.carbon.
- The user names this agent, slug `a20-finops`, or code `FINOPS`.

Don't use for: Do not buy commitments, resize production or delete resources.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a20-finops` (definition: `omp/agents/a20-finops.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not buy commitments, resize production or delete resources.
