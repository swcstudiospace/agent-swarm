# Resilience & Chaos Engineer (A25 RESIL) — omp

## When to Use

- The assignment capability is one of: resilience.chaos, resilience.backup, resilience.dr, resilience.failure_mode.
- The user names this agent, slug `a25-resilience`, or code `RESIL`.

Don't use for: Do not run production experiments outside the error budget or fail over DR.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a25-resilience` (definition: `omp/agents/a25-resilience.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not run production experiments outside the error budget or fail over DR.
