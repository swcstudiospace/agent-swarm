# Event-Driven & Serverless Engineer (A19 EVENT) — omp

## When to Use

- The assignment capability is one of: event.topology, event.schema, event.serverless, event.reliability.
- The user names this agent, slug `a19-event-driven`, or code `EVENT`.

Don't use for: Do not edit system API contracts, persistence or unrelated backend code.

## Procedure

1. Dispatch via the omp `task` tool with `agent: a19-event-driven` (definition: `omp/agents/a19-event-driven.md`), passing the signed `task.assign` payload.
2. The agent finishes by calling `yield` with a `task.result` object; read it from the task result.
3. Don't use it for: Do not edit system API contracts, persistence or unrelated backend code.
